# Quadcopter Frame Assembly

Quadcopter Frame Assembly

We are building a quadcopter frame in the X configuration, similar to the F450. The main deck will be a rectangular plate, and four arms will extend from its corners. Landing gear mounts will be added to the bottom of the arms. We'll use carbon fiber material (Part > Primitives > Box for the main deck and arms, Part > Boolean operations for assembly). Dimensions are chosen to be similar to the F450 but slightly simplified. Arm length is 250mm, main deck width is 200mm, height is 150mm. Landing gear legs are 30mm long and 3mm diameter.
