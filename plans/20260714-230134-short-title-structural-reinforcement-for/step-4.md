# Step 4 — Reinforce LandingLegs with Internal Stringers

Modify the existing 'Landing Leg' objects (Leg1 to Leg6). For each, create a new Part object: 'Leg_Stringer_30deg', 'Leg_Stringer_90deg', etc. Each 'Leg_Stringer' is a Part primitive: Box with dimensions 18x2x74mm. Position these stringers along the length of the original 'Landing Leg' (e.g., 'Landing Leg 1 (30deg)') at its central axis (y=9mm, z=0mm). Boolean cut the original 'Landing Leg' using the 'Leg_Stringer' to create a reinforced tube structure (18x18mm outer, 14x14mm inner). This increases the leg's torsional and bending stiffness. Use Part → Sketcher to draw a rectangular tube profile (width 18mm, height 18mm, thickness 2mm) and apply it via a pad or revolve feature, ensuring it matches the original leg length and is positioned correctly before boolean cutting the original leg shape.
